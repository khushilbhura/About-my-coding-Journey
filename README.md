# My Journey into AI & Software Engineering
This repository marks the beginning of my coding journey as I step into my freshman year of engineering. My goal is to build a strong foundation in programming, explore different technologies, and continuously improve my problem-solving and software development skills.

I will primarily be working with C, Java, and Python. I plan to strengthen my understanding of C programming and core computer science concepts, while further developing my existing knowledge of Java through hands-on practice and projects. Alongside these, Python is an area I am particularly interested in, and I intend to explore it through workshops, experimentation, and practical applications.

Rather than limiting myself to learning programming languages individually, I want to use this repository to document my progress, build projects, experiment with ideas, and learn from both successes and mistakes. Over time, I aim to move from fundamental programming exercises to more meaningful projects involving algorithms, data structures, automation, software development, and eventually Artificial Intelligence and Machine Learning.

As I progress through college, this repository will evolve with me — from my first programs and experiments to increasingly complex projects. My objective is to develop not just the ability to write code, but the ability to think computationally, solve problems effectively, build useful solutions, and continuously learn new technologies.

This is the starting point of my journey toward becoming a well-rounded engineer with a strong interest in Artificial Intelligence, software development, and emerging technologies.

Learn. Build. Experiment. Improve. Repeat.

This repository is where that journey begins.
